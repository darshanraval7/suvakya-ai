# ✨ Suvakya AI — "तव वचः, सुवाक्यम् करोतु"

**Suvakya AI** is a premium text-refinement SaaS application designed to transform rough, broken, informal thoughts, or regional phrases (Hinglish/Gujlish) into grammatically perfect, fluent, and professional English communication instantly.

---

## 🚀 Features

- **Triple Variant Output:** Instantly generates three context-specific versions:
  - **🌟 Best (Recommended):** The most natural and highly polished version.
  - **💼 Formal:** Suited perfectly for corporate corporate emails and business talks.
  - **🤝 Friendly:** Warm, natural, and highly approachable phrasing.
- **Tone Customization:** Select corporate, polite, casual, or persuasive tones dynamically.
- **Copy to Clipboard:** Seamless individual copying for quick actions.
- **Clean Micro-Interactions:** Modern, minimal UI engineered with responsive layouts.

---

## 🛠️ Tech Stack

- **Frontend:** React.js, Tailwind CSS (via CDN)
- **Backend:** Node.js, Express
- **AI Engine:** Google Gemini 2.5 Flash API (`@google/generative-ai`)
